그림 3. 단계별 로드맵
각 단계는 정량적 졸업 조건을 충족해야 다음 단계로 진행
0. MVP
공모전 · ~2026.12
  • Mount Check + OK 연동
  • 센서·영상 동기 수집
  • DMS 경고, 이벤트 클립
  • Pleos 에뮬레이터 연동
졸업: 실차 수집 데모 + 샘플 데이터 공개
1. 데이터 수집
0–12개월
  • 일반 거치대 + AI 설치 가이드
  • 품질 점수 기반 리워드
  • Pleos Connect 차량 대상 배포
졸업: 유효 데이터 비율 ≥ 70%, 누적 100만 km
2. 섀도 모드
6–18개월 · 비공식 베타
  • 전용 거치대(1st/3rd party)
  • 고정 캘리브레이션
  • 폰 AI 판단 vs 실제 운전 비교
  • 운전자에게 미노출
졸업: 판단 일치율·오탐률 목표 달성
3. 베타
12–24개월 · 옵트인
  • 운전자 노출 경고 기능
  • 차선이탈·전방추돌 경고(구형차 레트로핏)
  • 폰 이상감지 → 사전 경고
졸업: 오경보율 · 만족도 · 안전 지표
4. 적용
24개월~
  • 정식 서비스·구독 연계
  • 폰↔차량 연산 분담
  • 장기: 폰 이상 시 TOR → MRM(갓길 정차)
기능안전·법규 인증 범위 내 확장
