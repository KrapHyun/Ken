그림 2. 핵심 알고리즘 파이프라인
거치 → 자동 검사 → 수집 → 이벤트 감지 → 비식별화 → 업로드 → 품질 점수 → 리워드
1
Mount Check (거치 위치 검사)
IMU 중력벡터로 롤 |φ| < 5°, 피치 범위 확인 → 카메라 내부 파라미터로 예상 지평선 위치 계산(화면 높이 35–55% 이내) · 노면 영역 비율 30–60% · 선명도(라플라시안 분산) · 노출 · 전면 카메라 얼굴 검출(정면 ±30°) → 점수 ≥ 80 이면 OK 연동 시작
▼
2
동기화 수집
전방 영상(H.264) + IMU 100Hz + GPS + 기압 + 차량 신호(차속·조향·브레이크·크루즈)를 단일 단조 시계로 기록 · 폰 IMU 종가속도와 차속 미분값의 상호상관(cross-correlation)으로 시간 오프셋 자동 보정
▼
3
이벤트 감지 · DMS (온디바이스, 링버퍼 사전 10초 + 사후 5초 클립)
차량/IMU 규칙: 종가속도 ≤ −0.35g 급제동 · 3초 내 차속 변화 ≥ 30km/h · 조향 변화 ≥ 50° · 크루즈/ADAS 해제 순간 · 이상치 점수(z-score) 상위
운전자: EAR 기반 눈 감김, PERCLOS(60초) ≥ 0.15 → 졸음 경고 · 시선 이탈 2초 이상 → 전방 주시 경고(음성/진동)
▼
4
비식별화 → 업로드 → 품질 점수 → 리워드
얼굴·번호판 블러 후 저장(운전자 얼굴은 원본 미저장, 지표만) · 새벽 + Wi-Fi + 충전 조건에서 업로드 · Q = 0.3·화각 + 0.2·선명도 + 0.2·신호정합 + 0.3·희소성 · 리워드 = 기본단가 × 유효 주행 km × Q · 영상-차속 불일치 시 부정 수집으로 제외
